GSTR-1 Converter

Turn a Munim sales and credit/debit note export into the GSTN GSTR-1 Excel workbook (offline tool template V2.1) or a portal-ready JSON — segregated into B2B, B2CL, B2CS, exports and notes, with the HSN (B2B / B2C) and document summaries prepared for you.

Your data stays on your computer

The workbook is read and converted entirely inside your browser. Nothing is uploaded to us or to any server, so client sales data never leaves this machine.

Prefer to work without an internet connection? Download the offline version: a single HTML file that runs the same converter when opened from your computer.

    A preparation aid, not a filing

    The converter applies the reporting rules below to the data exactly as exported. It does not decide classification, rates, place of supply or whether a supply is taxable. Import the Excel into the GSTN offline tool (or upload the JSON) and review the portal summary before you file. Amendments of B2C small supplies (B2CSA) and of advances (ATA / ATADJA) are not generated.

    How each line is placed in GSTR-1

    Table / sheetRule applied to the Munim data
    4A, 4B, 6B, 6C · b2b,sez,deInvoices with a Billing GSTIN. One row per invoice per tax rate. Invoice Type maps to Regular B2B, SEZ with / without payment or Deemed export; Reverse Charge = Y only when flagged.
    5 · b2clInvoices with no GSTIN, inter-state (place of supply ≠ supplier state) and invoice value above the B2CL limit (₹1,00,000).
    6A · expInvoices with Type of Export EXPWP / EXPWOP (WPAY / WOPAY), or place of supply 96-Foreign Country. Port code and shipping bill are carried if present.
    7 · b2csAll other unregistered invoices (intra-state of any value; inter-state up to the limit), consolidated by place of supply + rate (+ e-commerce GSTIN). Credit / debit notes to unregistered persons with UR Type blank or B2CS are netted here — the same treatment Munim applies.
    8 · exempLines whose Item GST Type is Nil rated, Exempt or Non-GST, split into inter/intra-state and registered/unregistered.
    9B · cdnrCredit and debit notes with a GSTIN (note type C / D), one row per note per rate.
    9B · cdnurNotes to unregistered persons only where UR Type is B2CL, EXPWP or EXPWOP.
    11A / 11B · at, atadjDocument types Advance and Advance Adjustment, by place of supply and rate.
    12 · hsn(b2b), hsn(b2c)Every invoice and note line (excluding advances and Non-GST), credit notes negative, one row per HSN + rate (other units merged into the main UQC; a negative net quantity is reported as 0). Supplies to registered persons (B2B + CDNR) go to the B2B tab; unregistered (B2CL, B2CS, exports, CDNUR) to the B2C tab. Tax is computed per line (IGST if inter-state, else CGST + SGST). Services (SAC 99…) carry UQC “NA” with zero quantity.
    9A / 9C · b2ba, b2cla, expa, cdnra, cdnuraRows with the Original Invoice or Original Credit/Debit Note number filled are amendments of documents filed in an earlier period. They go to the amendment table matching where the document belongs, with the original number and date followed by the revised details in full. They are not counted in Table 13, not added to the HSN summary, and do not set the return period. The original must be from an earlier period, and amendments are allowed only up to the November return after the end of that financial year. B2C (small) amendments need B2CSA totals and are flagged instead.
    13 · docsEach document number is split into prefix + running number; each series is reported with the lowest and highest number, the count of documents issued and the number cancelled. Invoices, credit notes and debit notes are reported separately.

    The Excel follows the GSTN GSTR1_Excel_Workbook_Template V2.1 sheet by sheet. Import it into the GST Offline Tool (Import Files → Import Excel), review, and generate the JSON there. The JSON download skips that step: it is built in the GSTR-1 upload format and can be uploaded directly under Prepare Offline → Upload on the portal. It needs your GSTIN.

    Credit notes issued this month for goods sold in earlier months reduce this month’s figures. Where returns for an HSN, or for a state and rate in B2CS, exceed this month’s sales, the net is negative. The converter flags each such row so you can decide whether to report it as is or adjust through an amendment of the original period.

    Columns are matched by their header text, so their order does not matter: Document Type Code, Invoice Date / No., Billing Name / GSTIN, CR./DB. Note Date / No., Place of Supply, Item Description, HSN / SAC, Quantity, Item Unit, Taxable Value, GST Rate, CESS Amount, Reverse Charge, Item GST Type, Invoice Type, UR Type, Type of Export, shipping details, Applicable % of Tax Rate, Total Transaction Value, Is Invoice Cancelled and Ecommerce GSTIN.
